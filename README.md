## Descripción del Proyecto
Proyecto individual de análisis y desarrollo web elaborado utilizando exclusivamente las siguientes herramientas:

- **Análisis de Datos:**
- Archivo(s) de **Excel** con los datos estadísticos y de análisis.
- Archivo de **Word** con las normativas, decretos, resoluciones o modificaciones correspondientes.
- **Claude y Gemini:** Utilizados para el análisis de la información de los archivos de Word y Excel, y la generación del código HTML del sitio web.
- **Netlify:** Para la publicación y despliegue del sitio web.
- **GitHub:** Para la documentación y presentación del trabajo.
